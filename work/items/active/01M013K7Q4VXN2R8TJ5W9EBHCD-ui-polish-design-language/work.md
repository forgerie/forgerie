# UI polish — calm instrument panel design language

Raise the whole UI to a Linear-grade aesthetic bar without changing the
interaction paradigms. Direction approved 2026-08-16 from a live token-level
restyle: "calm instrument panel" — calm graphite dark, paper-white light, one
cobalt accent reserved for selection and primary action, status colors that
speak only when something has a status, separation by surface ramp instead of
outlines, and fluid intrinsic scales for type and space.

Baseline evidence: 28 pre-change captures (2 modes x 4 Z Fold 8 postures,
chat/inbox/files/git/settings) reviewed in the direction session; design
health scored 24/40. Direction slice (theme tokens + composer chrome +
tabular numerals) is live and approved.
