Choose the model that writes session titles in **Settings → Models → Session titles**. A small fast model can write each new session's title instead of the session's own model. The choice is saved as `sessionTitleModel` in Forgerie's config and applies to the next new session without a restart. Without a choice, or when no signed-in provider offers the model, each session's own model writes its title as before.
