Quiet the workspace panels and dialogs. Tool tabs, terminal shell tabs, mobile
main tabs, and panel header actions become ghost chrome — no boxes, with
selection as the one filled state. Dialog headers, footers, and framing borders
drop to hairlines. Filled primary actions now use the shared accent-on-bg text
convention everywhere (the undefined `--pi-accent-contrast` token is gone), and
the workspace-management dialog joins the shared type ramp and palette.
