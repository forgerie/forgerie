Choose a trigger's target projects on the Triggers page: one project, several, or All projects, which includes projects added later. The workflow picker lists only workflows every target project shares and says why a chosen workflow no longer fits. The last run and the run history count each fire's projects ("2 of 4 started") and list every project's outcome and session, with unavailable projects shown quietly. Run now can start in every target project or in one.
