Stop tables scrolling sideways in the transcript. A table wider than the reading column and the space beside it is now laid out as one card per row, each value carrying its column heading, so every cell stays reachable without a horizontal gesture that fights the transcript's own scroll. A table that fits is still a table, and table type drops one step so more tables fit. The decision reads two widths and nothing else, so the same table becomes cards on the folded phone and a table unfolded, and turns back on rotation.
