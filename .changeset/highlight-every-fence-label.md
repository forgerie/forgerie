Highlight a code fence with any grammar highlight.js ships, not its 36-language `common` subset. A `nix`, `dockerfile`, `cmake`, `powershell`, `elixir`, `yaml`, or `diff` fence now takes the five code colours instead of drawing as plain text, and the theme colours the token kinds those grammars emit (attribute names, compound scopes such as `hljs-title function_`, and a diff fence's added and removed lines).
