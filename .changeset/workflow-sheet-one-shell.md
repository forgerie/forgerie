Open every workflow in one sheet. A saved workflow, a proposal and a running workflow now share one layout: the plan is the page you read, drawn with the chat's own blocks, one section per stage, and the route, the inputs and the actions sit in a rail beside it. Each worker has a model picker. A proposal's stages and workers can be added and removed with Edit stages; that turns Start into Update the plan, which sends the changes to the agent as a note, while a model change alone still starts. A run marks the stage at work, shows a waiting stop on top as the chat's decision card and the result once it ends, and lists each worker's runs as tally blocks. A worker opens its live record beside the route, with Stop, a box to steer it, and its model, which applies from its next turn. Below 50rem the panes stack, and Start, Ask for changes, Dismiss and Stop stay in view.
