C · Runway

Percentages become time, because mid-work the question is "how long can I keep going". Each lane draws two marks on one timeline: the instant it runs dry at the current burn, and the instant it refills. Antigravity states no window length, so its pace is unknowable from one sample and the row says so instead of guessing. The unmetered lane has no level to convert, so it shows the only time-fact it owns: when it last refused work.
