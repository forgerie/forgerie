Quota shelf — the whole study

Twenty-five rounds. Every page renders the same decision as code, so the picture and the implementation are one thing. Rounds 22 onward draw the router's live payload; everything before draws a fixture taken by hand on 20 Sep. Nothing here is shipped — the live plugin still spends one row per account.
