Round 38 · a mark for a thing that is not a quantity

Round 37 made OpenRouter a roster entry, which was right, and then drew it as a full-width one-pixel line, which was not. A hairline is still a bar. It spans the same track as the meters above it, starts where they start and ends where they end, so it still reads as “something measured, drawn thin”. The row shape belongs on the shelf; the mark does not.

What OpenRouter is: money that is there or is not, with no cycle, no window and no maximum. The honest mark for that has no length. It sits at the lane origin, where every other lane begins, and says one of three things — fine, low, out. Every treatment below uses the same 5 px token in the same three colours; the choice is only about what, if anything, sits beside it.
