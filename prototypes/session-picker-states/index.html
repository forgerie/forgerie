Session picker: every state, one visual language

Prototype. The same render function draws every frame; only the data and the container width change. Sessions from all machines share one list, and the machine appears only as part of a row's location. Tokens, type, and the trace line come from the new client's theme.css.

1. The size ladder

Same sessions, five container widths. 260 px is the narrowest docked column. 475 px is the sheet on the folded phone. 704 px is the full-width overlay on the unfolded phone. The last frame sits beside the thread at 932 px, the unfolded-landscape shell.

2. Board states

What the whole picker looks like when the data is not simply "a list of sessions".

3. Every row state

One frame per state, in the order the board classifies them. The precedence is archived, blocked, errored, working, unread, open. Pinned changes the group, not the state.

4. Menus and confirmations

These open at window level in the real client, never clipped by the pane. Long press, right click, the Menu key, or the ⋯ on the selected row open the row menu.

5. The picker when it is closed

The thread header carries the opener. It shows one mark: a square when a session is blocked on you, a dot when something finished unread, nothing otherwise. Nothing else about the machine or the inbox leaks into the thread.

6. Keys and gestures

Carried over from the current client. Every command that a key reaches is also on a menu.

InputDoes
J / K, ↓ / ↑Move through the visible rows, in the order drawn. Collapsed groups are skipped.
Enter, SpaceOpen the row.
GSwitch grouping between state and project.
AShow or hide archived sessions.
EArchive the selected session. Shows the undo toast.
Shift+F10, Menu key, right click, long pressOpen the row menu.
EscClose a menu. Then close the sheet.
Ctrl+EnterNew session. Ctrl+Shift+Enter starts in rapidfire mode.

7. Coverage against the inventory

Every numbered item from docs/briefs/2026-09-29-session-picker-responsibilities.md, and where this sheet shows it. "Elsewhere" means the capability is kept but not drawn inside the picker.
