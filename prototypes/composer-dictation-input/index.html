Composer dictation input probe

Disposable harness for the microphone gesture. It calls browser media APIs only. It does not call Smart Turn, Whisper, or any network route.

Composer draft
Tap or hold the microphone. This box must not receive focus or open the keyboard when capture starts.
Idle. Press microphone to request permission and start capture.
Privacy boundary: production audio will go to this Forgerie gateway for endpointing and transcription, not the selected machine. This probe keeps no samples, writes no audio, and logs metadata only.
Gesture contract: Space down starts or holds, Space up releases, Enter or Space completes auto/manual listening, Escape aborts. Pointer cancel and page hidden/frozen/pagehide stop tracks fail-closed.
