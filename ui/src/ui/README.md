# System components

The shared space of the browser app. Every component here holds a reusable
decision and names no Forgerie concept. Search this list before you build a
component. If what you need is missing and its structure is generic, add it
here at its first call site, with its part and one line below.
The gates in `ui/gates/` enforce the rules.

One line per component: the name in backticks, its layer, and what it decides.

- `ActionFooter` (molecule): a pinned decision group with a reason and wrapping primary, secondary, or destructive actions; an input such as a reply box can take the actions' place under the reason; a failed action's problem shows in the failure ink above them.
- `TextSubmit` (molecule): one typed value and the action that sends it; the button drops under the field when the row is narrow, a refused value stays, and a refusal may offer one follow-up (such as Create) to confirm in place.
- `HeaderButton` (atom): a page header's one filled action, with a control-sized hit area; it can submit a form elsewhere on the page.
- `MenuButton` (molecule): rare commands one tap away behind a ⋯ button, with arrow keys, and a destructive command that asks twice in place; inside a list it opens at window level, above the button when the room below is short.
- `ChoiceList` (molecule): pick any number of rows; the legend counts the choice, a long list gets a search field, and a chosen id with no row stays visible.
- `ListSection` (molecule): a titled list of `<li>` rows on a settings-style page, with an optional readout beside the title, an empty text, a control under the rows, and a note on where the items live. `placement="document"` lines it up under a document page's fields.
- `ActionRow` (molecule): a list item that is not a link: name and status on one line, a detail under them, its commands at the end. `layout="head"` lines the commands up with the status; `"stacked"` puts the status under the name for a narrow row.
- `TitleField` (atom): a document title typed in place, in the title face, with its standfirst under it.
- `Lede` (atom): the one quiet paragraph that opens a page.
- `FilterChip` (atom): a filter that is on, above the list it narrows, with a clear button; not drawn when no filter is on.
- `CopyButton` (molecule): copies text on press and reports the result in a live region.
- `EventLine` (molecule): one quiet line for something that happened, with a tone dot, a time, an always-visible quote, and details on request.
- `EventSentence` (molecule): one quiet event told as a sentence after a tone dot; the words wrap instead of cutting off, a `<strong>` in them is the thing named and an `<a>` the way to it.
- `AlertCard` (molecule): a failure that may need the reader (or, in the warn tone, trouble that may clear on its own), drawn as a rail and wash in its tone: subject and phrase, explanation, wrapped code, quiet actions or a disclosure, and an output panel the actions fill; long code can be cut to a few lines with Show more.
- `MarkdownFragment` (atom): renders a short piece of Markdown inside a block, under the reply's link and image policy, with no outer margin.
- `Checklist` (molecule): shows progress on a list of tasks from `[x]`/`[~]`/`[ ]`/`[!]`/`[-]` lines, with an in-order meter and a count.
- `FileTree` (molecule): shows the files a change touched as a tree, marked added, changed or deleted, with single-child directories folded.
- `FactList` (molecule): shows a few headline values from `Label: value` lines; cells share a row and wrap by container width.
- `TreeItem` (atom): one row of an ARIA tree, indented by level, with a chevron on a branch or a toned mark on a leaf, a count, and a dot.
- `ToggleGroup` (molecule): a few choices of one setting as quiet pressed buttons, each with an optional count, a control-sized hit area, and an optional disabled state; as a form field it shows its label above them; with `multiple`, any number can be pressed (such as days of the week) and the buttons wrap.
- `FileTile` (atom): one file as a square: a picture fills it and any other file shows its type, the name under it, a note only for what the tile cannot show, and a corner remove.
- `FormLock` (atom): form controls that lock together, such as while a save is in flight: a fieldset with no frame of its own.
- `TileStrip` (molecule): one row of tiles that keeps its height and scrolls sideways, with each failure in full below.
- `SplitButton` (molecule): an action and the one setting that changes what it does, in one chip; the second half shows the setting in effect and opens its choices, each explained, at window level.
- `NoticeBar` (molecule): a full-width bar that stops the reader until they choose: a message and its actions, in a plain or alert tone.
- `CodeEditor` (molecule): an editable CodeMirror editor with line numbers, undo, Tab to indent, Ctrl/Cmd+S, and syntax colour from the file name; read-only, it still selects and copies.
- `MarkdownEditor` (organism): a Markdown file formatted like a transcript reply and edited in place with Tiptap, front matter as a read-only block above it, Ctrl/Cmd+S, and an optional notice with one action. `useMarkdownView` picks Rich or Source for a file and says when Rich is read-only or off.
- `Diagram` (molecule): draws Mermaid source once it stops changing, keeps a readable scale by scrolling, and shows the source when it cannot draw.
- `ClaimList` (molecule): shows findings tagged verified, inferred, opinion or unknown, with a text label and evidence under each.
- `Disclosure` (molecule): hides supporting material behind a one-line summary, closed by default and uncontrolled so it stays open while text streams.
- `CommandBlock` (molecule): one exact command, or what it printed, on a code surface with a copy button: each long line wraps under a hanging indent and is never cut silently; long text can be cut to a few lines with a toggle; a shell command shows a prompt mark the copy leaves out.
- `CommandList` (molecule): lists shell commands to run in order, each with a note and its own copy button, plus copy all.
- `BarChart` (molecule): draws a few numbers of one kind as bars from zero, with each value also stated as text.
- `CorrectionPanel` (molecule): states a correction loudly: the earlier claim struck through, the correct one strong, and the cause.
- `AsideList` (molecule): lists findings outside the question, each with a high, medium or low pill that reads without colour.
- `RailSection` (molecule): supporting content set smaller and muted on a hairline, optionally closed by a labelled rule that leads into the main text.
- `TallyRow` (molecule): content with one toned mark per unit of work in its margin; the marks open a panel, and a long tally ends in a count that keeps the worst tone it hides.
- `Timeline` (molecule): shows events in order with their times in one aligned column, joined by a rail.
- `QuoteFigure` (molecule): shows a quotation with its source as a caption in the code face.
- `Figure` (atom): one short figure (a share, a clock, an amount) in the code face with tabular digits, toned plain, muted, warn, bad or faint.
- `SignalDot` (atom): a yes-or-no signal with no level, neutral when on and danger when off, as one dot or as a run of dots across a lane.
- `PipRun` (atom): a count with no maximum, one pip per whole unit from the lane's start, a sliver for part of one, fading out past what the lane holds.
- `LogoMark` (atom): the app's mark, 1em square: plain marks in the text colour, one bad and two live marks in their tones.
- `PaceBar` (atom): a budget's share left against an even spend: a cut at pace, a hatch for a shortfall, a warn-to-danger bar for a surplus.
- `ErrorBoundary` (atom): replaces children that throw while drawing with a fallback, so everything around them keeps working.
- `LaneGrid` (molecule): named groups of measurement lanes on one set of columns, each group named by text or an icon, with optional captions, a marked block, trailing cells that span rows, a small action chip per block, a press on the whole block, an inline group whose one-reading blocks stand side by side as tokens, a group flag that tints its name or icon, a chosen block brought into view, and a roomy size.
- `Consequence` (molecule): one consequence the reader must see before acting, set apart by a wash and an icon, plain or warn.
- `FloatingPanel` (atom): the surface of a window-level panel that scrolls inside the height it gets; its host places it, and it sits inside the window edges until then.
- `OptionRow` (atom): one choice as a button: a name, a variant, a leading mark, short details (their own line, or the name's line giving way at the end), and a check on the choice in effect.
- `OptionList` (molecule): choices in named groups with search, one status line and a foot command; rows take focus, or follow a text field's highlight.
- `Shelf` (organism): a section at the foot of a list that opens and closes from a group header (closed, the header alone), scrolls on its own, and reports the room it sits in.
- `BadgeButton` (atom): an icon button drawn small with a control-sized hit area, a live-colour count of what waits on the reader (or a quiet count of what can wait), and a working dot.
- `IconCount` (atom): a quiet count beside a small icon, as a readout in a row; muted, never a signal.
- `SheetDialog` (organism): a modal sheet that is a card while the window has room and meets each edge as the room runs out, with back, title, text or icon actions, close, a scrolling body, and a footer.
- `StatusRow` (molecule): one pressable row for a running thing: a tone dot, a name, a detail, and a status that wraps under the name when the row is narrow.
- `ExchangeLog` (molecule): one worker's record, oldest first: words with the speaker in a margin, one line per action, and folded output.
- `ReplyBox` (molecule): a short text field with send and an optional second action; Enter sends and the text stays until the send succeeds.
- `QuestionCard` (molecule): a question that waits on the reader, with optional context under it (such as what someone else would answer), a reply box while open, and the answer once given.
- `DecisionRecord` (molecule): one decision made without the reader, as a log row: who and when, the question, the choice and its reason on one rule, a flag in the margin for the reader, a struck choice with its correction under it, and one quiet action at the first line's end.
- `Glyph` (atom): a one-colour mark from an SVG path on a 24-unit grid, at the size and colour of the text beside it.
- `Toast` (molecule): a short message that does not stop the reader: the message at full width with dismiss in its corner, and a foot row with the detail's first words (cut, they open the whole text) and one action; it always shows in the page's `ToastRegion`.
- `ToastRegion` (organism): the one place toasts appear, at the window's top end under the header, above the sheet and the thread; mounted once at the entry.
- `SearchField` (atom): one search box over a list, with a magnifier, in a control-sized row; its label is also its placeholder; optionally a ✕ that Escape also presses, a spinner while busy, and a hint under it.
- `HitRow` (molecule): one item a search found, as one press target: name and age, where it lives with quiet labels, the matched passage with its words marked (fewer lines in a short room), and a count of what else matched.
- `ResultList` (molecule): a search's answers scrolling in the room they get: skeleton rows before the first answer, a busy sweep over old rows, a progress line with a meter, an inline failure with retry, an empty text, a foot control for more; arrow keys move between rows.
- `FindBar` (molecule): a slim bar for stepping through found places ("2 of 7", previous, next, close; arrows and Escape), or one note about a found place with an optional action.
- `ListTools` (molecule): the controls that choose what a list shows, such as a switch and a search box, stacked and set apart from the list. An optional readout, such as a total, sits beside the last control and wraps under it when the row is narrow.
- `FileFrame` (organism): one file to read or edit: facts and notices above it, then the file on a framed surface that grows with its text, with an optional bar of tools along its top.
- `StatusChip` (molecule): a header's one status word as a toned pill, announced while it is quiet and hidden; with a panel it is a button that opens the long story under the header at the window's end, with a count that rides along and a ring for each new arrival.
- `StageStrip` (molecule): a whole process as one row of bars above an input, with a title, a status, and a count of what waits on the reader; parallel work is stacked bars, and a narrow strip drops the title first.
- `DecisionCard` (molecule): something in a thread that waits on the reader's decision, with the live edge and wash while open, its choices in a footer and a failed choice's reason above them, and one line saying what was decided once closed, which can link to what the decision made in a new tab, can take the failure ink, can carry what the decision produced under it, and takes focus when the reader's own choice closed the card; a card whose decision is made elsewhere has one action instead, which moves to the title line when the container is short; a card whose choices must stay in view can pin them beside the title, above the body, when the container is short.
- `TextAreaField` (atom): a labelled box for a few lines of prose that grows with its text, with a hint under it.
- `PinnedDock` (molecule): things that wait on the reader, pinned above an input under a counting heading; it takes at most 45% of the container height (a third on a container under 30rem tall) and scrolls inside past that.
- `Excerpt` (molecule): long content cut to its first few lines (a number the host may set) with a fade and a Show more toggle that appears only when it is cut; opened, it scrolls inside a share of the pane.
- `MarkStrip` (atom): past outcomes in a line, oldest first: a dot for one that went as planned, a square for a failure, a ring for one that never happened, a pulsing ring for one under way; past a limit the oldest fold into a count in the worst tone they hide.
- `RecordRow` (molecule): one record as one press target: a trouble mark, a two-line title, a time slot, meta parts that truncate from the end (or wrap to a second line when narrow), a foot with an outcome strip and words, and an inline action and ⋯ above the press target.
- `RecordGroup` (molecule): a counted group of records under a heading with a rule to the edge, opened and closed from the heading, its name in full ink when it wants the reader. `compact` takes less room above the heading in a short list.
- `PropertyList` (molecule): a document's property rows between two rules, under its title.
- `EmptyState` (molecule): an empty list as an invitation: an icon, a title, what goes here, and the action that adds the first one.
- `LoadingLines` (atom): a first read in progress: pulsing bars of different lengths and one line that says what is being read.
- `ReadoutLine` (molecule): one sentence about a state with the action that changes it at the line's end; the action wraps under the sentence first.
- `TextButton` (atom): a quiet action drawn as words at the text's size, with a control-sized target, a danger tone, and a pressed state for a toggle.
- `TimeField` (atom): a time of day as `HH:mm`, typed or picked with the browser's control in the reader's locale.
- `OptionPicker` (molecule): one choice as a chip that opens searchable options at window level; a blocked option stays visible and says why.
- `HeaderIcon` (atom): an icon-only header control, such as Close, muted until hovered, with a control-sized target and its label as name and tooltip.
- `BackButton` (atom): a page header's way back, named for where it goes, divided from the title by a rule; a narrow header keeps only its chevron.
- `PageSection` (molecule): a titled part of a document page: a small quiet heading set apart by the page's largest gap, then its content at full width, and a problem under it that describes the controls inside.
- `SettingsInput` (atom): one typed settings value, using the existing Settings input style.
- `SplitSheet` (organism): a modal sheet with a document and a rail beside it at 50rem and wider, one column that scrolls as one below that (the rail first or after the document), a lead above the document, a detail view that scrolls on its own in the document's place, and a foot in view at every size; pickers opened inside stay usable.
- `MarkdownProse` (atom): a whole Markdown document outside a chat, drawn by the reply's own renderer with every block a reply gets.
- `NumberedSections` (molecule): a document in sections whose headings carry the numbers of a list beside it, marked done or at work, added or removed; it brings a section into view on request and names the one being read.
- `RouteList` (molecule): a process as a flat numbered list: steps with one line and the reader's own block, items with their blocks in a margin column, a control under an item, folding into blocks, pressable rows, remove buttons and controls between steps for editing.
- `BlockRun` (atom): units of work as blocks on one line, in the tally's shape and tones, plus a solid live block for one that waits on the reader.
- `DetailPane` (molecule): one item opened in a pane: a way back, title, status and actions, a bar of settings, a body that scrolls on its own, and a foot that stays in view.
- `RuleBlock` (molecule): something to read before the text under it, marked by the decision card's rule in a tone, with a title, one quiet action, lines to take back one by one, content, and a note.
- `TermList` (atom): a few named values in two aligned columns, each value cut to two lines.
